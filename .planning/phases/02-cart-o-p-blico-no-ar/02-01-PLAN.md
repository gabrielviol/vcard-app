## Phase Goal

**As a** dono de um cartão digital, **I want to** ter meu cartão acessível publicamente em `/[slug]` e um QR pronto para circular, **so that** qualquer pessoa que escaneie ou receba o link veja meu cartão carregando rápido, sem cadastro e sem espera.

> Derivado da linha `**Goal:**` da Fase 2 em `.planning/ROADMAP.md` (que não está em formato de user story — ver nota ao final do planejamento).

<objective>
Primeira fatia vertical da fase: o cartão passa a existir publicamente. Cria o primeiro endpoint **não autenticado** do backend (`GET /public/cards/{slug}`), o primeiro Server Component com fetch de dados do frontend (`app/[slug]/page.tsx`) e a renderização mobile-first do cartão — implementando D-19 (seções vazias somem), D-20 (cartão mínimo já é público) e D-21 (nome + iniciais é estado válido, sem mensagem de "incompleto").

Purpose: sem esta fatia nada mais da fase tem sentido — o QR aponta para esta URL, o pré-aquecimento aquece esta rota e o 404 é o caminho alternativo dela.
Output: DTO público + endpoint + rota registrada fora do grupo autorizado, helper de fetch anônimo, página ISR (`revalidate = 60`) e componente de exibição.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet anônima → `GET /public/cards/{slug}` (.NET) | Primeira rota do backend alcançável sem Bearer token; o `slug` é entrada não confiável |
| Internet anônima → `GET /[slug]` (Next.js, Vercel) | Server Component executa fetch server-to-server; visitante nunca é autenticado |
| Next.js server → .NET API | Chamada server-to-server, sem CORS (CORS é enforcement de browser — `02-RESEARCH.md` Pattern 3) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | `PublicCardDto` / `GetBySlugHandler` | mitigate | Record deliberadamente estreito (Slug/FullName/Role/Company/PhotoUrl/SocialLinks); teste `GetBySlug_ExistingSlug_DoesNotLeakPrivateFields` assere `TryGetProperty == false` para `id`, `userId`, `phone`, `email`, `whatsappNumber`, `pixKey`, `pixKeyType`, `pixConsentConfirmed`, `isBranded`, `createdAt`, `updatedAt` |
| T-02-02 | Elevation of Privilege | Registro da rota em `Program.cs` | mitigate | `app.MapGet` top-level, nunca no grupo `cards` (que tem `.RequireAuthorization()` no nível do grupo); teste `GetBySlug_ExistingSlug_Returns200_WithoutAuthHeader` usa `HttpClient` sem `Authorization` como guarda de regressão |
